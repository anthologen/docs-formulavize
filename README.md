# docs-formulavize

The documentation website for
[formulavize](https://github.com/formulavize/formulavize), a split pane textual
editor for the **fiz** DSL: you write fiz recipes and they are compiled into
directed acyclic graphs that get drawn as you type.

This is a [VitePress](https://vitepress.dev) site built from the Markdown
under `docs/` organized into the following sections:

- **Getting Started**: what formulavize is.
- **Guide**: the fiz language explained one concept at a time.
- **Reference**: a fiz language reference.
- **App**: how to use the web app and CLI.

## Commands

Run from this package:

```sh
pnpm docs:dev      # local dev server
pnpm docs:build    # build the static site into docs/.vitepress/dist
pnpm docs:preview  # serve the built site
```

## Recipe Figures

Most fiz code blocks are followed by the graph that recipe actually renders to.
Those images are generated by the formulavize CLI and committed here, not built
with the site. See [FIGURES.md](FIGURES.md) before adding or regenerating one.
